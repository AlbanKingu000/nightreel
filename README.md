# Nightreel

A late-night movie discovery site. About a thousand well-known films with synopses, awards, trailers, cast
and crew, plus your own tickets (watchlist), ratings and reviews. No accounts, no API keys: everything ships
as static files.

> Personal portfolio project. "Nightreel" is a fictional brand, not a real service or company.
> No studio posters are used: every poster is an original card generated from the film's title.

**Stack**: React 19, TypeScript (strict), Vite, react-router, zod, zustand, Fuse.js; Vitest, Testing Library
and Playwright (with axe accessibility checks). The data pipeline runs on Node with tsx.

## Features

- **Home**: "Tonight's feature" marquee (a new award-winning pick every day), shelves for popular, most
  awarded, recent, hidden gems, Best Picture winners, genres and decades, plus personal rows once you save films.
- **Browse**: filter by genre, decade or year range, length and title; sort six ways. Filters live in the URL,
  so any view can be bookmarked or shared.
- **Search**: Ctrl+K or `/` from anywhere. Fuzzy, accent-insensitive search over titles, directors and actors.
- **Movie pages**: synopsis (linked to its Wikipedia article), awards, director and cast links, trailer
  player, "Where to watch" (JustWatch), share, similar films, your star rating and private review.
- **Poster cards**: CSS-only artwork. Each title hashes to a tint, an angle and one of four patterns, so a film
  always gets the same card (`src/components/Poster.tsx`, `src/domain/poster-art.ts`).
- **People, genres and collections**: filmographies, genre pages, curated collections.
- **Spin the reel**: pick a mood and length, and let the slot-machine reel choose tonight's film.
- **My tickets**: watchlist, watched, favorites, ratings and reviews, viewing stats, and backup export/import.

## Quick start

```bash
npm install
npm run dev
```

Then open the address Vite prints (usually http://localhost:5173).

## Rebuilding the movie data

The catalog in `public/data` is generated by:

```bash
npm run data
```

It reads only keyless, open sources and caches every response in `.cache/` (git-ignored), so reruns are fast:

1. **Wikidata** (SPARQL): the most widely covered films, with cast, crew, genres, runtime, release date,
   Oscars, YouTube trailer ids and popularity (the number of Wikipedia language editions).
2. **Wikipedia** (REST summaries): the synopsis text for each film. Images are not downloaded.
3. **YouTube oEmbed**: checks that each trailer is still playable.

The build fails rather than publishing a catalog with fewer than 500 films. A summary lands in
`data-report.json` (git-ignored).

## Tests

```bash
npm test            # unit and component tests (Vitest)
npm run test:cov    # with coverage (80% minimum)
npx playwright install chromium   # once, for end-to-end tests
npm run e2e         # end-to-end tests against the production build
npm run verify      # lint, typecheck, coverage, build and e2e
```

## Building and hosting

```bash
npm run build
npm run preview
```

`dist/` is a static site. `404.html` is a copy of the app shell, so deep links like `/movie/inception-2010`
work on static hosts such as GitHub Pages, Netlify or Cloudflare Pages.

## Project layout

```
scripts/        data pipeline (build-data.ts) and its tested helpers in scripts/lib
src/data        zod schemas and catalog loading
src/domain      pure logic: filters, sorting, search, recommendations, spin picker, stats
src/store       saved lists (zustand + localStorage), import/export
src/components  UI building blocks (ticket cards, shelves, search, trailer player, ...)
src/pages       one file per route
e2e/            Playwright tests
```

## Data sources and licenses

Text from Wikipedia, CC BY-SA 4.0; data from Wikidata, CC0.

- **Wikidata** ([CC0](https://creativecommons.org/publicdomain/zero/1.0/)): titles, dates, runtimes, genres,
  cast, crew, countries, Academy Awards, trailer ids and popularity.
- **Wikipedia** ([CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)): the synopsis on each
  movie page comes from the lead of the film's English Wikipedia article, and the page links to that article.
  The synopses in `public/data/details/*.json` stay under CC BY-SA 4.0.
- **Posters**: none. The cards are original, generated artwork; no studio posters or other third-party
  images are included.
- No ratings or other data from IMDb or other commercial databases.
- Fonts: Bebas Neue, Fraunces and Inter (SIL Open Font License), bundled via Fontsource.

## Privacy

Your tickets, ratings and reviews are stored only in your browser's localStorage. Nothing is sent anywhere.
Trailers load from YouTube's privacy-enhanced domain only after you press play.
